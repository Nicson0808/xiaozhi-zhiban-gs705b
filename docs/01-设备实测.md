# 01 设备实测

以下数据全部来自真机（`adb shell` 与环境接口实测），供移植参考。

## 1.1 标识

| 项 | 值 |
|---|---|
| 产品名 | 智伴儿童成长机器人 |
| 内部型号 | `GS705B`（`adb` 里 `product:Demo_7051H` / `device:q88_hd`） |
| CMIIT ID | 2018DP9338（2018 年型号核准） |
| 上市 | 2018.10 |

## 1.2 硬件

| 项 | 值 |
|---|---|
| SoC | ACTIONS OWL / ATS3605（`/proc/cpuinfo`: `Hardware: ACTIONS OWL SoC`） |
| CPU | ARMv7 Cortex-A5 ×4，900MHz（`CPU part 0xc05`） |
| 内存 | 57,704 kB（约 56MB），无 swap |
| 存储 | NAND，分区见 1.3 |
| 屏幕 | 800×480，`/dev/fb0`，16bpp RGB565，stride 960 |
| 触摸 | goodix-ts，`/dev/input/event2`，**只上报 KEY_HOME(102)/KEY_BACK(30)** |
| 加速度计 | `gsensor_mir3da` |
| WiFi | RTL8189FS（`wlan_8189fs.ko`），2.4G only |
| 功放 | NS4150 |
| 电池 | 2200mAh |
| 麦克风 | 2 mic + 1 ref（AEC），16kHz |

## 1.3 分区

| 分区 | 名称 | 挂载 | 说明 |
|---|---|---|---|
| nand0p1 | MISC | — | |
| nand0p2 | RECOVERY | — | |
| nand0p3 | **CONFIG** | — | 平台配置（含唤醒词、MAC、校准），**别乱写** |
| nand0p4 | SYSTEM | `/` squashfs **ro** | 原厂固件，只读保护 |
| nand0p5 | UPGRADE | `/var/upgrade` vfat rw | 9.8MB，小智装在这里 |
| nand0p6 | UDISK | `/mnt/udisk` vfat rw | 用户盘 |

## 1.4 系统

```
Linux (none) 3.10.52 #2 SMP PREEMPT Tue Aug 11 10:48:15 CST 2020 armv7l
rootfs: squashfs, 17.8MB, 100% 占用（不可写）
libc:   uClibc（hard-float ABI，VFPv4 + NEON）
```

启动链：`rcS` → 挂载 UPGRADE → 起 `manager` → manager 起 `launcher` / `sair` / `music_player` 等。

关键点：

- `rcS` 里 `export PATH=/var/upgrade:$PATH`，**这就是替换 sair 的原理**
- `/etc/test.sh` 会执行 `/var/upgrade/test.sh`（官方留的钩子，本项目用它做自启）
- `manager` 只有 15KB，是壳；UI 在 `/usr/bin/launcher`（唯一持有 `/dev/fb0`）

## 1.5 原厂助手行为

`/usr/bin/sair` 32KB，实测只做两件事：录 `AI_record.wav`、收云返回的 `ai_reply_%d.jsn`。
ASR/TTS 全在云端（`cloud.zhibankeji.com`），本地无任何对话能力——所以原厂服务一停，设备就废了。

## 1.6 交互语义（踩过的坑）

| 动作 | 实际行为 |
|---|---|
| 点屏幕 | 上报 `KEY_HOME(102)` → launcher 在「桌面 ↔ 助手窗口」间切换，并结束当前会话 |
| 唤醒词 | `zhi ban zhi ban`（**智伴智伴**），来自思必驰拼音关键词表，不是通用模型 |
| 语音命令词 | 声音大一点 / 声音小一点 / 停止播放 / 继续播放 / 上一首 / 下一首 |
| 打断播报 | 说「停止播放」，**不要点屏幕**（点屏幕会切走界面） |

唤醒词在启动日志里可见：

```
[CFG] 唤醒词: zhi ban zhi ban,sheng yin da yi dian,...
[WAKEUP] 产品ID: <dui-product-id>
[WAKEUP] 唤醒模型: /usr/local/resource/duilite/wakeup.bin
```

## 1.7 资源占用（实测）

| 进程 | RSS |
|---|---|
| launcher | 13.2MB |
| sair（小智） | 11.8MB |
| music_player / smart_player / mqtt_handle | 各 ~1MB |

空闲时 `free` 只剩 1–2MB，负载 5–10（4 核）。所以：**别在这台机器上想多任务**。
