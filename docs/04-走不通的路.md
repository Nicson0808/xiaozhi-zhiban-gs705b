# 04 走不通的路

这一篇记录**试过但没有继续**的方向，附证据与判断。目的是让后来者少花时间——包括我自己。

## 4.1 改唤醒词 → 阻塞在 CONFIG 分区

**目标**：把「智伴智伴」改成「你好小智」。

已完成的：

1. 解出平台配置 `/etc/user/def_config.bin` 的记录格式：

```
[u32 keylen][key][u32 vallen][u32 u32 valoff][value...]
```

2. 发现等长巧合并完成替换：`zhi ban zhi ban` 与 `ni hao xiao zhi` 都是 15 字符（16 字节含 `\0`），
   只改 14 个字节，不动任何偏移。
3. `mount --bind` 覆盖该文件，重启验证挂载生效（md5 一致）。

**结果**：sair 日志仍是 `zhi ban zhi ban`。

**原因**：`def_config.bin` 只是**出厂默认值**。真正生效的是 **CONFIG 分区 `/dev/nand0p3`**，
只读 dump 出来可以看到：

```
MAIN_WAKE_WORD
zhi ban zhi ban
```

**为什么停**：要改就得 `dd` 写裸 NAND。该分区大概率同时存 MAC、WiFi 校准、产品 ID，
且可能有整份校验；写坏的代价远大于"换个称呼"的收益。**不建议继续**。

## 4.2 换 UI 皮肤 → 闭源 launcher + 私有资源包

**目标**：把原厂桌面（智伴形象 + 学习卡片）换成小智风格。

实测结构：

| 组成 | 事实 |
|---|---|
| UI 进程 | `/usr/bin/launcher`，**全机唯一持有 `/dev/fb0`** |
| 资源 | `launcher.res`（340KB，内部 `PIC1…PICnn` 私有记录）+ `gb2312.ttf` 现渲染 |
| 动画 | `/usr/local/resource/swf/` 29 个 swf（1.8MB） |
| 根分区 | squashfs 只读，只能 bind mount 绕过 |

已经验证可行的一步：`mount --bind /var/upgrade/skin /usr/local/resource/swf`
开机生效（md5 校验通过），并留了 `/var/upgrade/skin_off` 开关可跳过挂载。

**为什么停**：换整套 = 反解 `PIC` 私有格式 + 重画整套 800×480 美术（背景/月球/三卡/图标），
按天计；只换形象又和整体画风不统一。**性价比不足**，残留已清理。

## 4.3 二进制补丁 → strip 后无从下手

**目标**：改 sair 让触摸不再结束会话。

- 触摸链路已确认：`touch_key` 读 `/dev/input/event2` → `on_key_event` → `process_pending_key` → 中断会话
- 但 sair 已 **strip**（无 `.symtab`），关键中文日志串在 `.text` 中找不到 pc 相对引用
  （疑似 Thumb/ARM 混合或经表间接引用），盲改风险远高于收益
- 本机也没有交叉编译环境（无 WSL/Docker/gcc），无法走源码编译路线

**结论**：放弃。若上游愿意加个 `touch_exit=0` 开关，成本很低，已建议给作者。

## 4.4 MCP 接入点恒显示「未连接」

控制台里那个灰点不是配置错误——**这版固件没实现客户端**：

- 源码与二进制双重确认：`mcp_endpoint` 只有「读配置 / 存配置 / 写 `.mcp_endpoint`」三处
- 没有任何建立连接的代码；二进制里搜「接入点连接 / MCP客户端 / mcp连接」= 0 条

**影响**：无。设备自身的 MCP 工具（音量、息屏、重启、清缓存、限时）走对话协议通道，`tools/list` 正常。

## 4.5 一句话点歌

模型会输出 `% play_music...` 这种伪指令，sair 只能当文本念出来——**设备侧没有"播放音频"入口**。

- 能用的：原生命令词「上一首 / 下一首 / 继续播放 / 停止播放」，走思必驰引擎直接控制 `music_player`
- 不能用的：让小智点歌。除非改 sair（无编译环境）或换支持音频播放的机型

## 4.6 自建服务端（暂缓，非不可行）

官方 `api.tenclass.net` 目前免费。若将来收费/停服，可自建 `xiaozhi-server`：

| 组件 | 免费方案 | 付费方案 | 家庭用量成本 |
|---|---|---|---|
| LLM | DeepSeek 赠额 / 通义豆包免费额度 | DeepSeek 约 1–2 元/百万 token | 3–6 元/月 |
| TTS | Edge TTS | 火山/腾讯 TTS | 0 元 |
| ASR | FunASR / sherpa 本地 | 云 ASR 按小时 | 本地 0 元；云 10–20 元/月 |

最低配置：2 核 2G（本地 ASR 建议 4G 以上）。

**降级影响**：测试服真停了也不会变砖——唤醒词、原生命令词、桌面 UI 都还在，只是"对话"失效。
