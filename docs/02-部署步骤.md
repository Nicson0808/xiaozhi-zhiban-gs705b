# 02 部署步骤

两条通道：**USB（adb）** 或 **WiFi（8080 HTTP 接口）**。后者更稳，实测 USB 用久了会掉线。

## 2.0 前置

| 项 | 要求 |
|---|---|
| 原厂固件 | ≥ 2.0.01.200907（本机 sair 时间戳 2020-09-07，刚好达标） |
| 上游产物 | 从 [moyu929/xiaozhi-zhiban](https://github.com/moyu929/xiaozhi-zhiban) 取 `device/xwebd/prebuilt/xwebd`、`device/assistant/prebuilt/sair` |
| 账号 | https://xiaozhi.me 注册 |

> 本仓库不提供二进制，请自行从上游获取（MIT）。

## 2.1 通道确认

```bash
# USB
adb devices -l          # 期望: model:GS705B  device
adb shell id            # 期望: uid=0(root)

# WiFi（同一局域网）
curl http://<device-ip>:8080/api/system
# 期望: {"model":"ats3605","wifi_connected":true,...}
```

## 2.2 部署顺序（不能反）

**先 xwebd，再 sair。** 卸载时反向：先 sair，再 xwebd。

### 方式 A：USB

```bash
adb push xwebd /var/upgrade/xwebd
adb shell chmod 755 /var/upgrade/xwebd
adb push sair  /var/upgrade/sair
adb shell chmod 755 /var/upgrade/sair
adb shell reboot
```

### 方式 B：WiFi（实测更省心）

```bash
# 上传（octet-stream + X-Filename 头）
curl -X POST -H "Content-Type: application/octet-stream" \
     -H "X-Filename: xwebd" --data-binary @xwebd \
     http://<device-ip>:8080/api/upload
curl -X POST -H "Content-Type: application/octet-stream" \
     -H "X-Filename: sair" --data-binary @sair \
     http://<device-ip>:8080/api/upload

# 重启
curl -X POST -H "Content-Length: 0" http://<device-ip>:8080/api/reboot
```

> `/var/upgrade` 是 vfat，上传后权限自动是 755，不需要 chmod。

## 2.3 验证

```bash
curl http://<device-ip>:8080/api/assistant/status
# 期望: "running":true, "native_running":false, "state":"Idle", "activated":true
```

设备端日志：

```
[INIT] 已加载缓存的MCP接入点: ...     # 若配置过
[WAKEUP] 唤醒词: zhi ban zhi ban,...
[WAKEUP] 唤醒检测已启动
```

## 2.4 绑定与开关

1. xiaozhi.me → 控制台 → 添加设备 → 输入面板里的 6 位激活码
2. **关闭该设备的 OTA 升级**（重要，见下）
3. 控制台配置智能体（人设、模型、音色）

### 为什么必须关 OTA

云端 OTA 只会下发**官方 ESP32 固件**。本机是炬芯 ATS3605，推下来既跑不了、也难恢复。

验证方法：重启后抓日志

```
[CFG] OTA响应: {"firmware":{"version":"4.1.5","url":""}, ...}
```

`url` 为空即安全。

## 2.5 回退原厂

删一个文件即可，原厂 `sair` 在只读分区里从未被修改：

```bash
rm -f /var/upgrade/sair && reboot
# 或面板「语音助手 → 卸载」
```

连续 3 次启动失败时，`boot_watchdog.sh` 也会自动回退。

## 2.6 备选：装开机钩子（强烈建议）

把 `scripts/test.sh` 推到 `/var/upgrade/test.sh`，可获得：telnet 15 分钟窗口、xwebd 自启、日志轮转、看门狗。

```bash
curl -X POST -H "Content-Type: application/octet-stream" \
     -H "X-Filename: test.sh" --data-binary @scripts/test.sh \
     http://<device-ip>:8080/api/upload
```

`/etc/test.sh` 会自动调用它（原厂预留的钩子）。
